# Working in this repository

Read CONTRIBUTING.md, docs/git-workflow.md, docs/commits.md and docs/pull-requests.md before
making commits or opening PRs. Use the repository's PR template and address review comments there.
Run the relevant checks from docs/testing.md. Do not publish videos or authorize platform access
as part of tests. Do not read or commit credentials, private footage or local workspace data.
Keep changes focused and preserve original user workspaces. New behavior needs a regression test.
